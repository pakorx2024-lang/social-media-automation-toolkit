# Getting Started

## 1. Prepare n8n

Run n8n using your preferred deployment method.

## 2. Import a workflow

Import a workflow from `workflows/n8n/`.

## 3. Configure credentials

Add your own AI and publishing credentials inside n8n. Do not place them in exported files.

## 4. Test generation

Start with generation only. Verify output format, language, tone, factual accuracy and platform constraints.

## 5. Add approval

Keep a human approval step before publishing.

## 6. Enable publishing

Connect the publishing adapters required by your own channels.

## 7. Measure results

Feed platform analytics back into the content pipeline so future content can be improved from real performance data.
