# Contributing

Thanks for contributing to the Social Media Automation Toolkit.

## What to contribute

Useful contributions include:

- n8n workflow improvements
- reusable content-generation skills
- translation workflows
- publishing adapters
- analytics integrations
- templates
- documentation
- tests and validation
- bug reports and reproducible examples

## Before opening a pull request

- Keep credentials and private data out of commits.
- Make examples generic.
- Document new environment variables or credentials.
- Test workflows with publishing disabled when possible.
- Explain what changed and how it was tested.

## Pull requests

A good pull request should contain:

1. A clear description.
2. The reason for the change.
3. Testing steps.
4. Any required configuration changes.
5. Screenshots or sample output when useful.

## Third-party content

Do not copy third-party prompts, examples, assets or code unless their license permits redistribution. Preserve required copyright and license notices.

## Code of conduct

Be respectful, constructive and focused on improving the project.
